== DESCRIPTION ==

**🏆 Media Library Folders for WordPress - Media, Posts, Pages & Users**

[Documentation](https://yalogica.com/docs/mediacommander/?utm_source=wordpress.org&utm_medium=ref&utm_campaign=docs) | [Upgrade to Pro](https://yalogica.com/mediacommander/?utm_source=wordpress.org&utm_medium=ref&utm_campaign=promo)

MediaCommander adds drag & drop folders to your WordPress media library and goes one step further than typical folder plugins: the same folder tree also organizes your **posts, pages, users, custom post types and WooCommerce content**.

Every folder is 100% virtual. Moving or renaming a folder never changes file paths, permalinks or attachment URLs, so your existing content and SEO are untouched.

Links (shortcuts). Hold Alt (or Ctrl+Shift) while dragging an item to a folder: the item stays in its original folder and also appears in the new one, marked with a "Link" badge. One post, page or image can now live in as many folders as you need, cross-reference a page across several projects without moving or duplicating anything.

For a complete step-by-step guide, check out our article on [How to Create Folders in WordPress Media Library](https://yalogica.com/blog/how-to-create-folders-in-wordpress-media-library/).

== Frequently Asked Questions ==

= How do I create folders in the WordPress media library? =

Activate the plugin, open **Media > Library** and click "Plus Folder" in the sidebar panel. Name the folder, pick a color and start dragging items into it. The same sidebar is available for posts, pages, users and custom post types (Pro).

= Can I place the same item in several folders? =

Yes. Hold Alt (or Ctrl+Shift) while dragging an item to a folder to create a link (shortcut) instead of moving it. The item remains in the original folder and also appears in the new one, marked with a "Link" badge. To remove a link, drag the item from the linked folder to "All Items" or "Uncategorized" - the original placement stays intact. This feature is available in the Pro version.

= Can I organize posts and pages into folders, not just media? =

Yes, that is what MediaCommander is built for. The Pro version extends the folder tree to posts, pages, users, custom post types and WooCommerce content, so your whole admin area is organized in one consistent structure.

= Will folders change my file URLs or permalinks? =

No. Folders are purely virtual, they act like labels. Moving, renaming or deleting a folder never touches the uploads directory or changes any URL.

= What happens when a folder is deleted? =

Only the link between the folder and its items is removed. Everything stays safe and available in the "Uncategorized" virtual folder. There is also an optional setting to delete attached items together with a folder if you really want that.

= Does MediaCommander work with Gutenberg and page builders? =

Yes. Folders appear in the block editor and the Classic Editor out of the box, and in any page builder (Elementor, Divi, WP Bakery, Beaver, Bricks, Brizy and others) that uses the standard WordPress media modal for selecting images.

= Can any user create and modify folders? =

That is up to the administrator. Fine-grained permission settings let you control create/view/edit/delete rights per user or role, for example giving authors read-only access to shared folders.

= Can the folders sidebar be hidden? =

Yes, click the toggle button above the screen title. Press it again to bring the sidebar back.

= Nothing happened after the image was replaced =

Most likely your browser is still serving the cached old image. Perform a hard refresh (Ctrl+F5 on Windows, Cmd+R on Mac).

= Is MediaCommander free? =

The free version includes unlimited folders and subfolders, Gutenberg and Classic Editor support, personal and shared folders, and media replacement. Pro adds folders for posts, pages and custom post types, links (shortcuts), advanced permissions, custom sorting, ZIP download, import from other plugins and priority support.

Yes. Alongside the yearly plan there is a lifetime license, pay once and use the plugin with unlimited updates.

== Installation ==

Setup is easy and takes only a few minutes.

1. Download the plugin from wordpress.org, unpack it and upload the **mediacommander** folder to your **wp-content/plugins/** directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to **WordPress menu → Media** to create your first folder and start organizing your files.

You're done. Enjoy.
